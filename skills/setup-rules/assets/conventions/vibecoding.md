
## Vibe Coding

- Each change in this talk = own commit.
- Keep root `CHANGELOG.md` in Chinese per [Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and SemVer.
- Log each notable change under `[Unreleased]` in the same commit; refactors go under `Changed`.
- On release, rename `[Unreleased]` to `[x.y.z] - YYYY-MM-DD` and open a new empty one.
