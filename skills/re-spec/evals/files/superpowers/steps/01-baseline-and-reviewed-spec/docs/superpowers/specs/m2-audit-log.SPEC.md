# m2 · 审计日志 设计

**Status:** reviewed

## Goal

满足监管迎检：控制台可追溯密钥重置、应用停用与机构停用等关键操作。

## User-facing Behavior

- 平台管理员在「安全审计 → 审计日志」按时间范围筛选记录。
- 点击记录查看变更前后。
- 平台管理员可批量删除过期审计记录，避免列表过长。

## Architecture & Decisions

- 审计记录只追加，保留 90 天后归档到对象存储。
- 审计写入与业务操作在同一事务内完成。

## Testing

- 集成测试：每类关键操作写入一条审计记录。

## Non-goals

- 审计告警推送。
