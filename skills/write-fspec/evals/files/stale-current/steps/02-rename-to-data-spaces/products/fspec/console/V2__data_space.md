# V2 · 关联应用改为关联空间

## 一、变更摘要

机构列表「关联应用」改名为「关联空间」，仍展示数量。

**动机**：机构改按数据空间组织应用。

## 二、变更清单

| 操作 | 定位符 | 说明 |
|---|---|---|
| `RENAME` | `page.orgs.fields.关联应用` | 改叫「关联空间」 |
| `MODIFY` | `page.orgs.fields.关联空间` | 说明改为「该机构加入的数据空间数量」 |
