# Format

Authoritative format of 功能规格说明书. Skeletons: `templates.md`. Merge: `merge.md`.

## Naming

- Product line dir: lowercase ASCII, aligned with the prototype or frontend app (`console`, `portal`).
- Versions: per line, from 1, contiguous, no gaps or duplicates; `V<n>__` in the filename equals frontmatter `version`.
- Slug: lowercase ASCII with underscores summarizing the change (`data_space`); propose it with Chinese title for user to confirm.

## Frontmatter

V file:

```yaml
---
product: console        # = directory name
version: 2              # = V2__ in the filename
slug: data_space
title: 数据空间架构重构  # one Chinese line
type: change            # baseline | change; V1 is always baseline
status: draft           # draft | active
created: 2026-08-05     # absolute date
---
```

`CURRENT.md` starts with generated comment, before frontmatter:

```
<!-- GENERATED by fspec — 勿手改。要改内容请新增 V 文件。 -->
---
product: console
synthesized_from: [1, 2]   # merged active versions, ascending
generated: 2026-08-05
generator: fspec
---
```

## Locators

Lowercase dot paths; segments may be Chinese.

| Form | Target |
|---|---|
| `nav.<group>` | Nav group |
| `nav.<group>.<pageId>` | Nav item |
| `page.<pageId>` | Page |
| `page.<pageId>.layout` | Its 布局骨架 subsection |
| `page.<pageId>.fields.<field>` | A field or table column |
| `page.<pageId>.actions.<action>` | An action |
| `page.<pageId>.states` | Its 状态与流转 subsection |
| `flow.<name>` | Cross-page flow |
| `term.<term>` | 术语表 entry |
| `global.<rule>` | A 全局约定 rule |
| `donts.<item>` | A 明确不做 item |

Page ids equal the prototype or frontend ids (`apps`, `complianceStats`).

## Operations

| Op | Meaning | Locator | Also give |
|---|---|---|---|
| `ADD` | New | must **not** exist | New page: all six subsections; new field/action: its row |
| `MODIFY` | Change content in place | must exist | Full replacement content |
| `RENAME` | New name, same meaning | must exist | The new name |
| `MOVE` | New position, same content | must exist | Target locator |
| `REMOVE` | Delete | must exist | One-line reason |

`RENAME` plus content change = `RENAME` row, then `MODIFY` row using new name; one combined row is ambiguous to merge.

## V1 chapters (fixed order)

1. **产品定位与角色**: who uses it, which problem it solves, role × module matrix (可见 / 可写 / 不可见).
2. **信息架构**: nav tree, group → menu → page id.
3. **全局约定**: shared layout, list/detail/form patterns, state and feedback rules, permission visibility. Pages note only exceptions.
4. **页面规格**: one section per page with the six subsections below.
5. **关键流程**: cross-page flows as numbered steps; mermaid when branchy.
6. **术语表**: Chinese, English/id, definition; locks outward copy and enum names.
7. **明确不做**: never skip, see below.

## Page subsections (fixed order; empty → 「无」, never delete)

| Subsection | Write | Don't write |
|---|---|---|
| 标识 | Page id, route, entry point | — |
| 目标 | One line: why the user comes here | Background essays |
| 布局骨架 | Region-level text wireframe | Pixels, colors, sizes, spacing |
| 数据与字段 | Table 字段 / 类型 / 示例值 / 可编辑 / 说明, realistic examples | DB columns, API field names |
| 操作 | Table 操作 / 触发位置 / 前置条件 / 结果 / 二次确认 | Backend implementation |
| 状态与流转 | Empty, loading, no-permission, error, extremes; where it leads and comes from | — |

前置条件 is most skipped column, main reason builds go wrong: whether a button is disabled or hidden cannot be guessed.

## Vn chapters (fixed order)

1. **变更摘要**: one line plus 动机 (why, not what).
2. **变更清单**: operation / locator / note; the only table the merge reads.
3. **新增页面规格**: six subsections in full.
4. **修改的页面**: deltas only, each naming the subsection it replaces.
5. **流程与术语变更**
6. **影响面**: pages indirectly affected but unchanged.

## 明确不做

Builders fail by adding what nobody asked for (bulk export, remember-me, an AI summary card), not by omitting. One concrete line each:

- Features not built, with a one-line reason.
- UI elements that must not appear (no breadcrumbs, no card lists).
- Rejected options, so they are not proposed again.

「不要过度设计」 is noise; 「列表页一律用表格，不用卡片」 is useful.
