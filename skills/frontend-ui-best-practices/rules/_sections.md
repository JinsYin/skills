# Sections

定义所有分类、排序、影响级别与描述。括号内的 section ID 即规则文件名前缀。

影响级别按**违反给用户造成的后果**划分：

| 级别 | 含义 |
|---|---|
| CRITICAL | 造成数据丢失或不可恢复的误操作 |
| HIGH | 用户无法完成任务，或被明确误导 |
| MEDIUM | 能完成任务但体验受损、需要额外认知负担 |
| LOW | 观感不一致 |

---

## 1. 技术栈与结构 (stack)

**Impact:** LOW
**Description:** 前端依赖选型、项目结构与模块文档约定。不影响单个界面能否用，但决定新人和 agent 能否判断某个包该放什么、某个依赖为什么在这里。
